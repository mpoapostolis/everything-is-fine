# Recommended itch.io Settings

## Project

- **Kind of project:** HTML
- **Classification:** Game
- **Release status:** Released
- **Pricing:** $0 or donate
- **Genre:** Adventure
- **Made with:** Phaser
- **Languages:** English
- **Multiplayer:** Singleplayer
- **Inputs:** Keyboard, Touchscreen

## Upload

1. Upload `everything-is-fine-html5.zip`.
2. Mark the file as **This file will be played in the browser**.
3. Use **Embed in page** at **960 × 540**.
4. Turn **Click to play** on so audio starts reliably.
5. Turn **Fullscreen button** on.
6. Turn **Mobile friendly** on.
7. Leave scrollbars off.
8. Use `branding/embed-background-1280x720.png` as the optional pre-play background.

## Artwork

- **Cover image:** `branding/cover-630x500.png`
- **Page banner:** `branding/banner-960x300.png`
- **Screenshots:** upload all five files from `screenshots/` in numeric order
- **Screenshot layout:** Sidebar, so the images remain visible beside the playable embed

## Theme

- **Page background:** `#080a0f`
- **Content background:** `#0d1016`
- **Text:** `#d8dce4`
- **Links / buttons:** `#e4c878`
- **Headers:** `#9aabc2`
- **Font:** VT323 if available; otherwise use a clean monospace font
- **Layout:** Single column for the game embed, with the screenshot sidebar enabled

Check contrast after applying the banner; the description must remain easy to read on a dark display.

## Metadata and disclosure

- Add the content notice from `page-copy.md`.
- Select **Yes** for generative AI use.
- Disclose these areas: **Graphics, Sound, Text & Dialog, Code**.
- Do not describe the generated graphics or music as fully handmade.

## Safer publishing sequence

1. Save the project as Draft.
2. Set visibility to Restricted and share the secret URL with one trusted tester.
3. Test the page in a signed-out/private browser window on desktop and mobile.
4. Confirm save/checkpoints, audio start, fullscreen, touch controls, and the ending.
5. Replace `[YOUR NAME]` in the credits.
6. Change visibility to Public only after the private-page test passes.
