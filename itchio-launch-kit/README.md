# EVERYTHING IS FINE — itch.io Launch Kit

This folder contains the files and copy needed to publish the game on itch.io.

## Ready-to-upload files

- `everything-is-fine-html5.zip` — browser build; upload this as an HTML game.
- `branding/cover-630x500.png` — itch.io cover image.
- `branding/banner-960x300.png` — page banner.
- `branding/embed-background-1280x720.png` — optional click-to-play background.
- `screenshots/01-home.png` through `05-homecoming.png` — page screenshots.

## Ready-to-paste text

- `page-copy.md` — title, short description, full description, controls, content notice, credits, and AI disclosure.
- `itch-settings.md` — recommended itch.io settings, tags, theme, and publishing sequence.
- `social-copy.md` — launch posts in English and Greek.
- `upload-checklist.md` — final pre-publication checklist.
- `branding/PROMPTS.md` — the prompts used to create the store artwork.

## One manual edit before publishing

Replace `[YOUR NAME]` in `page-copy.md` with the public creator name you want shown on the page.

The game itself was not rewritten for this launch kit. The only release-code change was a small startup compatibility fix required for Vite to produce the HTML5 build.
