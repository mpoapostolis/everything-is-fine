# Upload Checklist

## Before upload

- [ ] Replace `[YOUR NAME]` in `page-copy.md`.
- [ ] Decide whether the creator page uses your real name or a studio name.
- [ ] Confirm the v0.1.0 label is correct.
- [ ] Keep the project private/restricted for the first online test.

## itch.io page

- [ ] Create an HTML game named `EVERYTHING IS FINE`.
- [ ] Paste the short and full descriptions from `page-copy.md`.
- [ ] Upload `everything-is-fine-html5.zip` and mark it for browser play.
- [ ] Apply the embed settings from `itch-settings.md`.
- [ ] Upload the cover, banner, and five screenshots.
- [ ] Add the content notice.
- [ ] Add the credits and AI disclosure.
- [ ] Apply tags, genre, input, language, and theme settings.

## Private online test

- [ ] Open the secret itch.io URL in a signed-out/private browser window.
- [ ] Start the game and verify that audio begins after the click.
- [ ] Test movement, interaction, notebook, calls, help, and fullscreen.
- [ ] Refresh after a checkpoint and confirm Continue works.
- [ ] Verify the final scene and credits.
- [ ] Test one mobile/touch device if mobile friendly remains enabled.
- [ ] Check that all images are sharp and no text is cropped.

## Publish

- [ ] Make the page Public.
- [ ] Copy the public URL into `social-copy.md`.
- [ ] Publish the English and/or Greek launch post.
- [ ] Download the public ZIP once and keep it as the release archive.
